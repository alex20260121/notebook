# 本地导入文件故障
导入表数据时出现: ERROR 3948 (42000): Loading local data is disabled; this must be enabled on both the client and server sides
## 原因
服务端和客户关闭了`local_infile`，需要两者都要打开。
## 解决方法
1. 可以通过`SQL`查询`local_infile`变量是否打开，"OFF"为关闭、"ON"为打开;
```sql
SHOW GLOBAL VARIABLES LIKE 'local_infile';
```
2. 临时打开；
```sql
SET GLOBAL local_infile = 1;
```
3. 持久化保存，直接写入`mysql.cnf`配置文件。
```bash
[mysqld]
local_infile=1
```
