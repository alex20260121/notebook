# 磁盘扩容

多数Linux系统管理磁盘分区分为**标准分区**和**lvm**逻辑卷分区。大部份Linux发行版都通用。

## 1. 标准分区扩容

标准分区(Standard Partition ) 直接基于 MBR 或 GPT 创建的常规分区，分配后大小不易在线动态调整。

扩容标准分区本质上需要完成两件事情：

1. 扩大分区边界（修改分区表，让分区包含更多扇区）。
2. 扩大文件系统（让 ext4 或 xfs 等文件系统识别并使用新增的空间）。

### 1.1. `growpart`在线扩容

目前最简单、安全且普遍支持在线不关机扩容的工具是 growpart。

- 查看磁盘、分区、文件系统类型:

```bash
# 查看磁盘
lsblk

# 查看分区挂载及占用情况和文件系统类型
df -hT
```
> [!TIP]
> 假设要扩容的磁盘是`/dev/vdb`，目标分区是`/dev/vdb1`挂载目录为`/var`。
