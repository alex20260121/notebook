# 磁盘扩容

多数Linux系统管理磁盘分区分为**标准分区**和**lvm**逻辑卷分区。大部份Linux发行版都通用。

## 1. 标准分区扩容

标准分区(Standard Partition ) 直接基于 MBR 或 GPT 创建的常规分区，分配后大小不易在线动态调整。

扩容标准分区本质上需要完成两件事情：

1. 扩大分区边界（修改分区表，让分区包含更多扇区）。
2. 扩大文件系统（让 ext4 或 xfs 等文件系统识别并使用新增的空间）。

### 1.1. `growpart`在线扩容

目前最简单、安全且普遍支持在线不关机扩容的工具是 growpart。

- 查看磁盘、分区、文件系统类型:

```bash
# 查看磁盘
lsblk

# 查看分区挂载及占用情况和文件系统类型
df -hT
```
> [!TIP]
> 假设要扩容的磁盘是`/dev/vdb`，目标分区是`/dev/vdb1`挂载目录为`/var`。

- 安装扩容工具:

`Ubuntu/Debian`发行版
```bash
sudo apt update && sudo apt install -y cloud-guest-utils
```

`RHEL/Centos`发行版
```bash
sudo yum install -y cloud-utils-growpart
```

- 扩展分区边界：
> [!IMPORTANT]
> 注意：磁盘名称和分区编号之间有一个空格。

```bash
# 语法: growpart <磁盘设备路径> <分区编号>
sudo growpart /dev/sda 1
```
> [!TIP]
> 输出若显示 CHANGED: partition=1 ... 则代表分区表已成功扩大。

- 扩展文件系统
分区扩大后，文件系统并不会自动变大，必须根据文件系统类型执行对应的刷新命令：

  - ext4 或 ext3，使用 resize2fs，后面跟分区路径：
  ```bash
  sudo resize2fs /dev/sda1
  ```
  - 文件系统是 xfs：
  ```bash
  xfs_growfs /
  ```
